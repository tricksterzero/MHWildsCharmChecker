# タスク: MHWilds 護石スクショ読み取り → CSV出力

## 入力
- スクショフォルダ: `C:\Program Files (x86)\Steam\userdata\39293390\760\remote\2246340\screenshots`
- 正規化辞書（読み取り専用・変更禁止）: `C:\File\Program\MHWildsCharmChecker\skill-decoration-map.json`
- 対象日付: 実行時にチャットで指定された YYYYMMDD。未指定なら処理前に確認する。

## 手順

### 1. 対象ファイルの絞り込み（画像を開く前に行う）
フォルダ内のファイル名を一覧取得し、**先頭8桁が指定日付と一致するファイル名だけ**を対象リストにする。これはテキスト照合であり、この段階で画像を開かないこと。対象外のファイルは一切読み込まない。

### 2. 各画像の読み取り（対象リストのみ）
対象画像を1枚ずつ開く。1画像=護石1個前提。
まず「装備詳細」パネルの有無を確認し、無ければ即スキップ（手順4のa）。あれば以下を読む。
- スキル: 「装備スキル」欄のスキル名とレベルを画面表示の上から順に（最大3）。
- スロット: 各アイコンの ①レベル=穴下部の三角の数（1個=Lv1, 2個=Lv2, 3個=Lv3）、②種別=右肩マーク（剣=武器, 兜=防具）。

### 3. スキル名の正規化（117正規名への分類）
辞書 `decorations[].skills` のキー（全117種）を唯一の正解候補とし、読み取り名を必ずこの中の1つに分類する（自由補正は不可）。
- **完全一致**（全角半角・ローマ数字・丸数字・ＵＰ等を正規化後）→ 確定採用。
- **補正採用**: 完全一致しないが、117種のうち唯一1つだけが軽微な誤差（数文字の誤字・記号差・欠落）で対応し紛れが無い → その正規名で採用し「補正リスト」に記録。
- **保留→警告**: 候補が複数ありうる（例「水属性攻撃強化」と「氷属性攻撃強化」）、またはどれとも遠い → 採用せずスキップ。安全側に倒し、紛らわしければ必ず警告へ。

### 4. スキップ（採用せず警告に記録: `ファイル名 — 理由`）
- a: 装備詳細パネルが無い
- b: 護石が複数写る等、1セットを特定できない
- c: スキル名が手順3で保留になった（読み取り名も併記）
- d: スロットの三角数・種別、またはスキル名/レベルの判定確度が低い

## 出力

### CSV（採用分のみ、1行ずつ）
```
スキル1,Lv,スキル2,Lv,スキル3,Lv,防具枠1,防具枠2,防具枠3,武器枠1,武器枠2,武器枠3
```
- 列1-6: スキル（表示順。2つなら列5-6=`,0`、1つなら列3-6=`,0,,0`）
- 列7-9: 防具スロット（兜マーク）のレベルを降順、空き=0
- 列10-12: 武器スロット（剣マーク）のレベルを降順、空き=0
- 補正採用を含む行も通常出力に混ぜる。
- 例（通常弾・通常矢強化1 / 挑戦者1 / 防具①① / 武器①）:
  `通常弾・通常矢強化,1,挑戦者,1,,0,1,1,0,1,0,0`

### 補正リスト
補正採用した護石: `ファイル名 — 読み取り名 → 正規名`

### 警告レポート
各警告 `ファイル名 — 理由`、末尾に**警告件数の合計**。
